# Delivered scope / Moodrobe 2

| Area | Delivered | Boundary |
|---|---|---|
| Design and language | New studio identity; full English UI | User-entered names remain as entered |
| Garment imagery | Photographic sample assets and personal uploads | Samples are AI-generated; no virtual try-on |
| Real neural inference | Local all-MiniLM sentence embeddings and neural ranking | Text input only; encoder is not fashion-trained |
| Personal learning | Logistic preference head trained from labelled outfit vectors | Small local dataset, no accuracy claim |
| Structural assembly | Complete owned outfits, availability, layers, base diversity | Explicit deterministic constraints remain |
| Before AI activation | Clearly labelled starter suggestions | Rules are never relabelled as neural results |
| Wardrobe | Photo compression, colour estimate, metadata, descriptions, filters | No automatic vision category/background segmentation |
| Daily use | Check-in, brief, optional weather, saved edits, calendar and diary | Local browser, no account/sync |
| Circularity | 60-day rediscovery and anchored AI edits, external reuse links | No automatic listing, donation or push notifications |
| Biometrics | Camera mirror, local audio, imported RR/RMSSD | No emotion inference or model input |
| Privacy | Local storage, granular optional consent, backup/import and deletion | No legal certification or completed DPIA claimed |
| Research | Exploratory neural-vs-rules A/B collection, CSV | Not a controlled pilot or effectiveness evidence |
| Deployment | Static build, private Sites publication, Vercel configuration | Vercel account deployment is a separate action |

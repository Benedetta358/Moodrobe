# Sample wardrobe imagery

`sample-wardrobe.png` was generated with the built-in Imagegen tool for this project. It depicts unbranded demonstration garments, not items claimed to be physically owned by a visitor. The app uses CSS background positioning to display the sixteen cells without altering the source bitmap. Personal photographs are displayed from local uploads instead.

## Generation prompt

Use case: product-mockup. Asset type: photographic sample wardrobe contact sheet for a fashion web app. Create a perfectly aligned FOUR by FOUR grid, exactly 16 equally sized SQUARE cells, no gutters, all with the same pure warm-white (#f4f3ee) seamless studio background. Each cell contains one centered full-length photorealistic unbranded clothing item, clearly separated from all other cells, fully inside its square with at least 12 percent padding. Top-down luxury e-commerce flat lay photography, soft natural shadows, real fabric weave, meticulous realistic texture. NO humans, NO mannequin, NO text, NO labels, NO logos, NO watermark, no decorative props. Exact row-major order: row1: ivory cotton crewneck knit sweater; pale blue button-front shirt; terracotta short-sleeve t-shirt; sand beige tailored blazer. Row2: sage green button cardigan; chocolate brown long wool coat; beige tailored trousers; indigo straight-leg jeans. Row3: taupe pleated midi skirt; black sleeveless midi dress; pair of ivory low-top sneakers; pair of brown leather loafers. Row4: pair of black ballet flats; brown leather shoulder handbag; rust silk scarf neatly folded; white cotton short-sleeve t-shirt. The grid is essential: 4 columns and 4 rows equal dimensions, 16 garments total. Crisp highly realistic isolated packshots, full items no cropped sleeves or hems. Square overall composition.
